# 乐龄聆听计划 · Leling Listening

课程**大作业**：面向长辈的独立音乐陪听产品。

> 不是把音乐「放给」老人听，而是坐下来陪他一句一句地听。

- **在线体验**：https://a-egg-and-a-box.github.io/leling-listening-pro/
- 提交材料另有《产品说明文档》（.docx）与《答辩 PPT》（.pptx）
- 题目与开题报告保持不变

---

## 一、一句话说清产品

把「听音乐」拆成 **一屏一步** 的四步小流程，每一步只问一件事、只给一个按钮。
不懂音乐也能听，不会用手机也能用，看不见屏幕也能用。

## 二、四步玩法

1. **选曲** —— 按「入门 / 进阶 / 欣赏」三档挑一首，选项不超过 3 个
2. **分段聆听** —— 一句一句听，每句都配了真实时间点，一点就跳过去
3. **引导提问** —— 听完这一句，回答一个很朴素的问题（是慢慢往上走，还是一下子跳上去？）
4. **记录聆听** —— 留下「我今天听了什么」，下次可以接着来

## 三、为什么是「陪听」而不是「播放器」

| 常见音乐 App | 乐龄聆听计划 |
|---|---|
| 一次给一整张列表，让你自己挑 | 一次只问一件事，选项不超过 3 个 |
| 播放 / 暂停 / 进度条 / 音量，一排按钮 | 每屏一个大按钮，铺满整行 |
| 想听第几句要自己拖进度条 | 「▶ 听这一句」直接跳到该句，到点还会自动停 |
| 听完没有反馈 | 听完提一个问题，再揭晓这首是什么 |
| 默认字号、浅灰字、小图标 | 三档大字号、高对比深色字、纯文字大按钮 |

## 四、六屏向导

```
首页 ─→ 选难度 ─→ 选曲 ─┬─→ 分段聆听（第 1 句）→ 引导提问 ─→ 第 2 句 … ─→ 揭晓答案 ─→ 聆听记录
                         └─→ 这里没有？ ─→ 自选曲（粘贴 B 站链接 / BV 号）
```

## 五、适老化设计

- **看得清**：字号小 / 中 / 大三档（一键切换、自动记住）；高对比暖米色底 + 深墨色字；描边加粗
- **点得准**：按钮铺满整行，最小高度 46–60px；一屏内选项不超过 3 个
- **听得懂**：全部文案是大白话，不使用「旋律动机」「配器」这类术语
- **有人陪**：语音朗读默认开启；「陪听」大屏模式把当前的问题放大显示
- **纯听觉可用**：每屏内容都有语音播报，看不见屏幕也能顺着听下去
- **一步一按钮**：任意时刻屏幕上只有一个「下一步」，不会迷路

## 六、无障碍

- **朗读**：`speechSynthesis`。首次朗读需要用户先点一下页面（浏览器安全策略要求由手势触发）；自动挑选中文语音包；设备确实没有中文语音时，按钮降级为「🔇 本机无朗读」，并提示改用家人念或系统读屏
- **播报区**：`aria-live="polite"`，屏幕阅读器会读出当前屏的提示
- **键盘**：`1–9` 选第 N 个按钮、`Enter` 确认、`Esc` 返回上一步、`空格` 重读本屏
- **焦点**：`focus-visible` 4px 高对比描边

## 七、曲库

17 首精选 + 1 条「自选曲」模板：

- **入门 · 一听就耳熟**：彼得与狼、致爱丽丝、欢乐颂、卡农、茉莉花
- **进阶 · 听两遍才有味道**：蓝色多瑙河、二泉映月、月光奏鸣曲、梁祝、天鹅湖
- **欣赏 · 名曲慢慢听**：命运交响曲、沃尔塔瓦河、1812 序曲、图画展览会、自新大陆、培尔·金特 · 晨景、春之祭

每首曲子自带：B 站视频号（`source.bvid`）、多乐章分 P（`source.page`）、3 句的进入时间与时长（`parts[].t / .dur`），以及该句的引导问题与提示。


## 九、技术实现

- **纯静态**：无后端、无构建、无框架，原生 JS 模块，跑在 GitHub Pages 上
- **真实音乐**：通过 `player.bilibili.com` 的 iframe 嵌入真实录音，**绝不使用电子合成音冒充音乐**
- **不接大模型**：引导对话全部是内置的离线脚本，不需要 API Key、不需要联网请求大模型，打开就能用
- **两个关键取舍**（因为 B 站 iframe 不提供播放控制接口）：
  - 「跳到某一句」＝ 重载 iframe 并改 URL 参数（`&t=秒` 定位时间点、`&p=分P` 定位乐章）
  - 「听完自动停」＝ 起播后启动计时器，到点把 iframe 重载为暂停状态
- **记录**：`localStorage`（`leling-pro.records.v1`），最多保留 50 条

## 十、与本课程小作业的关系

**小作业**是改进老师原版「音乐作品助手」，通用版与乐龄版共用一套底座（`shared/`）：
https://a-egg-and-a-box.github.io/leling-listening/

**大作业**（本仓库）是完全独立重写的另一款产品：一屏一步的分步向导、面向长辈重新设计交互，两份作业不共用任何一个代码文件。

## 十一、已知局限

- 音乐播放依赖网络与 B 站音源；音源失效或受地区限制时，可以粘贴别的 B 站链接继续听
- 「到点自动停」的计时从播放器重载那一刻开始算，网络较慢时句尾会有偏差，因此文案统一写「约 N 秒」
- 曲库 17 首为精选；自选曲目需要自己填每一句的起点时间
- 聆听记录保存在本机浏览器，换设备或清理缓存会丢失
- 时间点优先取 B 站官方分段或 UP 主简介里的时间轴，没有官方分段时按该作品常见的进入位置配置，允许十几秒误差，页面提供手动微调入口
